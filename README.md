# specops

A real-time collaborative system design workspace. Describe a system in plain English, let AI map it onto a shared canvas, refine with collaborators, and generate a technical specification from the resulting graph.

## Features

- **Collaborative Canvas** — Real-time shared canvas powered by Liveblocks and React Flow with live cursors and presence indicators
- **AI Architecture Generation** — Generate system designs from natural language prompts via durable background tasks
- **Starter Templates** — Curated library of prebuilt system design patterns (monolith, microservices, event-driven, serverless, etc.)
- **Spec Generation** — Convert canvas graphs into persistent Markdown technical specifications
- **Authentication & Projects** — User sign-in, project creation, ownership, and collaborator access

## Tech Stack

TanStack Start, React 19, Tailwind CSS v4, shadcn/ui, Liveblocks, React Flow, Prisma, PostgreSQL, Cloudflare R2
