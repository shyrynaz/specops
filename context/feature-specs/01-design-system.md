Read `AGENTS.md` before starting.

We are adding the design system and UI primitives components.

Install and configure `shadcn/ui`.

Add these shadcn/ui components to the project.

- Button
- Input
- Select
- Card
- TextArea
- ScrollArea
- Tabs
- Dialog
- Drawer

Do not modify the generated `components/ui` files after installation.

Also install lucide-react for icons.

Create a `lib/utils` directory with a reusable `cn` utility function for merging Tailwind CSS classes.

Ensure all components match the design system and theme in `styles.css`.

### Check when done

- All components match the design system and theme in `styles.css`.
- All components import without errors.
- `cn()` utility function merges Tailwind CSS classes correctly.
